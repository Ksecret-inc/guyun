- 바로 보기: https://ksecret-inc.github.io/guyun/
- 원본 데이터: 구글 시트 「[교육용 더미] 매출 데이터 2026」 (교육용 가상 데이터)

## 동작 방식

- 페이지를 열 때마다 구글 시트를 직접 읽습니다. 시트를 고치면 새로고침만 하면 반영됩니다.
- 시트를 못 읽으면 `index.html` 안에 들어 있는 2026-11-20 사본을 보여 주고, 오른쪽 위 점이 노란색으로 바뀝니다.
- 시트 열 이름(`월, 제품, 채널, 판매수량, 정가(원), 할인율(%), 매출(원)`)은 바꾸지 마세요. 열 순서는 바뀌어도 됩니다.
